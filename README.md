# Jetpack Compose Digital Business Card

A simple Android digital business card application developed using Kotlin and Jetpack Compose.

## Features

- Displays a profile image.
- Shows a name and professional title.
- Presents contact information in a clean layout.
- Uses a vertical `Column` layout and a `Row` for contact details.
- Includes a customized contact button with rounded corners.
- Displays a Toast message when the button is pressed.

## Technologies

- Kotlin
- Jetpack Compose
- Android SDK
- Material Design

## About

This project was developed as a university assignment to practice building user interfaces with Jetpack Compose, arranging components, and customizing UI elements.
